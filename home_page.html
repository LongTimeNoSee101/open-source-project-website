Welcome to NKPLab

An open-source hub created to share electronic projects.

Free to access, explore, and download all hardware designs and documentation.

What you can access

Explore and download all project assets:

  • Technical specifications
  • Schematic designs & PCB layouts
  • Enclosure & frame designs (3D files)
  • Firmware & software source code
  • Detailed documentation

Software Editions

While our hardware is fully open-source, some projects offer two software tiers:

  • Community Edition (Free): Covers all essential features for everyday use.
  • PRO Edition (Paid): Unlocks an enhanced UI, advanced utilities, and dedicated tools.

Priced accessibly for everyone, these contributions directly fund our R&D to build better open-source hardware.

Hardware Options

  • Fully Assembled: Ready-to-use products out of the box.
  • DIY Hardware Kit: Includes all required components, PCBs, and hardware so you don't need to source them manually.
